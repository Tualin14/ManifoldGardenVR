# Manifold Garden VR（MGVR）

**简体中文** | [English](README.en.md)

Manifold Garden 的非官方 PC VR Mod，支持头部跟踪、Quest 手柄操作、重力切换、射线交互、VR 菜单和震动反馈。 **需要拥有原游戏。**

**当前版本：1.0.5** · [下载](https://github.com/Tualin14/ManifoldGardenVR/releases) · [演示视频（Bilibili）](https://www.bilibili.com/video/BV1Vtx76MEev/) · [问题反馈](https://github.com/Tualin14/ManifoldGardenVR/issues)

已验证环境：Windows x64、Steam 版、Quest 3、Virtual Desktop（VDXR）。其他设备与运行时尚未系统验证。

> [!WARNING]
> **VR 舒适度提醒：** 重力切换、连续移动、平滑转向，以及 **游戏中部分场景和过场的空间变化与视觉效果**，可能引起眩晕、恶心、视觉疲劳等不适。
> 建议先短时间体验，并优先尝试分段转向。 **如感到不适，请立即停止游玩，摘下头显并休息，不要勉强继续。**

请遵循头显厂商的安全说明，例如 [Meta Quest 健康与安全警告](https://www.meta.com/legal/quest/health-and-safety-warnings/)。

## 安装与启动

1. 下载 **`MGVR-1.0.5-Windows-x64.zip`**。GitHub 的 `Source code` 是源码，不能直接安装。
2. 退出游戏并备份存档。Steam 中右键游戏 → **管理 → 浏览本地文件**，打开包含 `ManifoldGarden.exe` 的目录。
3. 将压缩包内的 **全部内容**复制到该目录，合并文件夹并覆盖同名文件。更新时保留 `UserData` 和存档；已有其他加载器或 Mod
   时，先备份同名文件。
4. 连接头显并进入 PCVR。在 Steam → **游戏属性 → 启动选项**中填入 **`--vr`**，然后启动游戏。

运行包已包含 MelonLoader 和 XR 文件。 **首次启动需要联网下载并生成适配文件，请等待完成。** 如提示缺少
.NET，安装 [.NET 6 Desktop Runtime x64](https://dotnet.microsoft.com/en-us/download/dotnet/6.0)。

主菜单会自动进入 VR；戴好头显、面向正前方短暂停稳即可。要恢复桌面模式， **移除 `--vr` 并重启游戏**。

## Quest 手柄操作

| 按钮           | 功能                             |
|----------------|----------------------------------|
| 左摇杆         | 移动                             |
| 右摇杆左右     | 转向                             |
| 左握把         | 跑步                             |
| 右扳机         | 沿右手射线拾取、放下或交互       |
| 右握把         | 切换重力                         |
| A / B          | 顺时针 / 逆时针旋转持有的物体    |
| 长按 Y 约 1 秒 | 归位；先让摇杆回中并松开其他操作 |
| X              | 打开菜单 / 继续游戏              |

扳机在食指处，握把在手柄侧面。左扳机和摇杆按下默认无动作；手柄菜单键由头显或串流工具处理。

**菜单：** 右手射线瞄准，按下并松开右扳机点击，按住可拖动滑条；点击“返回”返回上页。长按 Y 可重新放置菜单。

**过场继续：** 放置上帝方块后的过场提示长按时，按住右扳机继续；进度条与剩余秒数会显示当前进度，松开会停止推进。

**测试选关：** 在暂停菜单中打开。选关页点击“返回”或按 X 回到暂停菜单，再按 X 继续游戏。

## VR 设置

在游戏 **设定 → VR 设置** 中调整分段 / 平滑转向、分段角度、平滑转向速度、震动开关及强度。修改立即生效并保存，页面下方附操作图。

Mod 新增界面与操作图支持简体中文，其他游戏语言显示英文。震动需要同时开启原游戏的震动总开关。

## 已知问题与反馈

测试选关可能导致游戏状态或进度异常，尤其是结局等特殊流程。建议备份存档并使用测试存档。
